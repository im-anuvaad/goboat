Move to another server

Moves this installation to a new server: the account, settings, apps, env vars, certificates and every file in the apps' data folders. The new server builds every app while this one keeps serving; then Switch now hands over, typically in under a minute. Logs, metrics and the local backup copies stay behind (the backups in the bucket are used by the new server).
